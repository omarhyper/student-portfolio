## Features Implemented

### HTML
- Semantic elements (`header`, `nav`, `main`, `section`, `footer`, `article`)
- Forms, tables, images, hyperlinks, lists
- Multimedia (audio + video placeholders)

### CSS
- External stylesheet
- Responsive design (mobile-friendly)
- Flexbox and CSS Grid
- Navigation styling + mobile hamburger menu
- Hover transitions and simple animations
- Consistent colour scheme

### JavaScript
- Event handling
- DOM manipulation
- Form validation (empty fields, email format, phone digits only)
- Dynamic content updates
- Arrays + functions
- Interactive task management (add / complete / delete) with localStorage

## How to Use

1. Open `index.html` in a browser.
2. For the planner and contact form to work fully, serve the folder with a local server  
   (or just open the files directly – most features still work).
3. Replace placeholder images:
   - `images/profile.jpg` – your photo
   - `images/project1.jpg`, `project2.jpg`, `project3.jpg` – screenshots
4. Optional: add `media/intro.mp3` and `media/project-demo.mp4`.
